MonitorClient 🔒
A bounded queue and one I/O worker serialize socket access. A timed-out exchange closes the connection, so replies can never match a later request.
ObservationSession 🔒
Owns a parent’s observation session for the complete HTTP stream lifetime. Drop queues cancellation without blocking a Tokio worker. Lease expiry is the fallback if the bounded queue is full or setup was cancelled in flight.
