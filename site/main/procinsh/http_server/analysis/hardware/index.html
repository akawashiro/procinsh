Module hardware 

Source
Expand description

GPUs, RDMA NICs, accelerators and NVSwitches with the PCIe bridges between them, the paths between devices, and the processes holding their character devices.

Interprets helper-acquired sysfs/procfs text and links entirely in memory. This module opens no host files; PCI config space and vendor libraries are unused.
