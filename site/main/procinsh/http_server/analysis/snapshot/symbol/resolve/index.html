elf_address
Convert a corrected runtime address into an ELF address, accounting for the mapping offset, PIE/ASLR load bias, and page-aligned segment mappings.
instruction_address
Correct a saved return address before selecting its mapping. The currently executing instruction must be passed with return_address = false.
resolve_frame
Resolve an ELF address without changing a frame or the ELF cache. Returns None only when no symbol, source location, or inline frame is found. DWARF reads only bounded in-memory sections under the ELF’s private lock.
