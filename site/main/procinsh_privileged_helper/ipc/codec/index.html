Native-endian binary values for the private, same-machine IPC connection.

Struct fields follow their declared wire order; enum variants have explicit byte tags. Strings and collections have u32 lengths. Integers and floats use their native byte representation. Rust padding, pointers and container layouts are never copied. The peers run on the same machine and are built together.
