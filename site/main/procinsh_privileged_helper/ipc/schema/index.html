procinsh_privileged_helper::ipc

Module schema 

Source
Expand description

Closed monitor operations and structured replies. No request accepts a path, arbitrary process-memory read, syscall number, file descriptor, or caller-selected limit. Mapped ELF requests select an existing executable mapping by its start address; the helper independently verifies the process, mapped file identity and file ranges.

Frames have a four-byte native-endian length and a native binary payload. Requests are at most 1 KiB, responses at most 1 GiB, and at most 64 requests may queue in the application. Socket I/O and application requests have 30-second deadlines. Each side treats an invalid/truncated frame or a timeout as a fatal connection error. Sessions expire after 15 seconds without polling and are capped at 32 per kind. Event polling never blocks waiting for a new observation.
