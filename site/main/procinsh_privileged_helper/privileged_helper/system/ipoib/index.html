Module ipoib 

Source
Expand description

InfiniBand port GIDs of network destinations reached over IPoIB.

An IPoIB neighbor’s hardware address is 20 bytes: flags and the remote IPoIB QPN, then the remote port GID. /proc/net/arp truncates it, so neighbors are dumped with rtnetlink in the collector’s network namespace. Only sockets of that namespace can use the result; other namespaces have their own tables.
