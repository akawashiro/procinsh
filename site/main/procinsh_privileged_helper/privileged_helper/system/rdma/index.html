Module rdma 

Source
Expand description

RDMA queue pairs, connection manager IDs and port addresses, observed read-only through RDMA netlink, rtnetlink IPoIB neighbors and sysfs.

RDMA netlink is queried only when class/infiniband under the sysfs root lists a device, so a host without RDMA never autoloads ib_core. Verbs data transfers bypass the kernel; queue pairs carry no per-QP traffic observation.
