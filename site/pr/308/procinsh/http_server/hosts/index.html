Module hosts 

Source
Expand description

Multiple hosts: a hub accepts agent links and serves each agent’s processes, process details and SPACE observations; an agent links to a hub and answers the hub’s requests with its own privileged helper.

The hub sends the agent the same closed helper requests it sends its own helper, so remote hosts need no separate API. Agent links use length-prefixed frames over TCP without TLS. A hub on a non-loopback address requires a shared token. Agents collect only while the hub has viewers for them.
