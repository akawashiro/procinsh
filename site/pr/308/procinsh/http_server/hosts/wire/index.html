procinsh::http_server::hosts

Module wire 

Source
Expand description

Agent link framing: u32 big-endian length, one encoding byte, then a JSON Message. Larger messages are gzip-compressed; snapshots compress well.

The hub sends the same closed MonitorRequests the HTTP layer sends to its own helper. The agent processes acquisition replies on its host and returns an AgentResponse ready for HTTP output. JSON framing supports links between hosts with different architectures.
