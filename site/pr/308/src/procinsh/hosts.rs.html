1//! Multiple hosts: a hub accepts agent links and serves each agent's processes,
2//! process details and SPACE observations; an agent links to a hub and answers
3//! the hub's requests with its own privileged helper.
4//!
5//! The hub sends the agent the same closed helper requests it sends its own
6//! helper, so remote hosts need no separate API. Agent links use length-prefixed
7//! frames over TCP without TLS. A hub on a non-loopback address requires a shared
8//! token. Agents collect only while the hub has viewers for them.
9//!
