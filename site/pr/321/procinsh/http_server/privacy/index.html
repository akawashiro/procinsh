Privacy mode: mask sensitive text before a reply leaves this process.

§Interface

  • enable (pub(super)): fn enable(level: u8) -> anyhow::Result<()>.
  • enabled (pub(super)): fn enabled() -> bool.
  • scrub_response (pub(super)): fn scrub_response(response: &mut MonitorResponse).
  • pseudonym (pub(super)): fn pseudonym(value: &str) -> String.

The privileged helper does not read environments or process memory in this mode. Everything else it returns passes through scrub_response: identifying fields are replaced whole, and other strings are scanned by logblur, with this machine’s host name, IDs and login users preloaded. A masked value becomes ░ + 8 hex digits + ░, a keyed hash that is consistent within this run, so distinct addresses stay distinct, but cannot be linked across runs or hosts. The original text is never sent.
