Module dependency graph

Arrows mean user → dependency (利用する側 → 利用される側). Opposite arrows show mutual dependencies; longer cycles can be followed along the arrows.

These graphs show internal library module dependencies detected by cargo-modules 0.27.0 for the default Linux build, excluding external crates and test-only code. References to functions, types and traits are folded into their containing modules. Module ownership and dependencies within the same displayed module are omitted. This is static analysis, not a runtime call graph.

Scroll each graph horizontally or vertically. Use the zoom buttons or your browser's pinch zoom. You can also open the SVG directly. The overview combines all descendants of each top-level module; the detail view preserves child modules and direct references across module boundaries.
